## Sobre o projeto

Projeto desenvolvido para a AEP do curso de Engenharia de Software,
com o objetivo de criar uma aplicação em linguagem C para auxiliar
no planejamento, registro e acompanhamento das ações do Programa
Saúde na Escola (PSE).

## Objetivo do sistema

O sistema PSE em Ação foi desenvolvido com o objetivo de auxiliar na 
organização e no gerenciamento das ações coletivas do Programa Saúde na 
Escola (PSE). Permite cadastrar escolas e profissionais, registrar ações 
e datas ocupadas, consultar informações e acompanhar as atividades 
planejadas e realizadas.

## Tecnologias utilizadas

- Linguagem C.
- Dev-C++.
- Sistema operacional Windows.

## Como executar

1. Abra o Dev-C++.
2. Clique em **Arquivo → Abrir** e selecione o arquivo do código-fonte.
3. Após abrir o código, pressione **F11** para Compilar e Executar.
4. Aguarde a compilação. Caso não ocorram erros, o programa será iniciado automaticamente.

## Funcionalidades

- Cadastro de ações, escolas, profissionais e datas ocupadas.
- Consulta de ações, escolas e profissionais.
- Listagem de datas ocupadas.
- Geração de relatórios de ações planejadas e realizadas.
- Alteração de informações e status das ações.
- Remoção de cadastros.
